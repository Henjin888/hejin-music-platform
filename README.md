## Features

- AI-powered music creation
- Lyrics generation
- Cover art generation
- Shorts script creation
- Release copy generation

## Tech Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Supabase
- OpenAI
- Stripe

## Getting Started

```bash
npm install
npm run dev
```

## Environment Variables

配置以下环境变量：

- NEXT_PUBLIC_SUPABASE_URL
- SUPABASE_SERVICE_ROLE_KEY
- OPENAI_API_KEY
- STRIPE_SECRET_KEY
- NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY
